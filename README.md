# Event_SMLFM
Repository for event-based SMLFM. Including basic introduction and relative code packages.

# Contents of the repository
Python-based codes for Event-based SMLFM data processing. 
Core function blocks: MLA mask generation, Event-based 2D localisation, Event-based 3D-SMLFM localisation, Event-based diffusion analysis, Event-based 3D locs rendering (work in progress). 

Config file for the conda environment for the python scripts provided.

Example Event-SMLFM data sets.
